# Calculadora de Correção Monetária - INPC

Uma aplicação web para cálculo de correção monetária utilizando o índice INPC (Índice Nacional de Preços ao Consumidor).

## 🚀 Tecnologias Utilizadas

- React 18.2.0
- Material-UI (MUI) 5.14.14
- React Router DOM 6.18.0
- React PDF Renderer 3.1.14
- Tailwind CSS 3.3.3
- Google Apps Script (Backend)

## 📋 Pré-requisitos

* [**Node.js**](https://nodejs.org/en/download) (versão 14 ou superior)
* **npm** (incluído com Node.js)

## 🔧 Instalação e Execução

### 1. Clone o repositório
```bash
git clone https://github.com/ma-serra/Calculo-Correcao-Monetaria-INPC.git
cd Calculo-Correcao-Monetaria-INPC
```

### 2. Instale as dependências
```bash
npm install
```

### 3. Execute a aplicação

#### Modo Desenvolvimento
```bash
npm start
```
A aplicação será aberta automaticamente em `http://localhost:3000`

#### Build de Produção
```bash
npm run build
```
Os arquivos otimizados serão gerados na pasta `/build`

#### Servir Build de Produção
```bash
npx serve -s build
```

## 📚 Funcionalidades

- ✅ Cálculo de correção monetária com base no INPC
- ✅ Interface responsiva e intuitiva
- ✅ Geração de relatórios em PDF
- ✅ Salvamento de cálculos no Google Sheets
- ✅ Navegação entre páginas de cálculo e visualização de PDF
